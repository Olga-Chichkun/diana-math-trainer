# 1. Цель задачи

Создать первую рабочую версию web-приложения **DIANA LEVEL** — персонального учебного приложения для ученицы 4 класса.

Приложение должно помогать ребёнку осваивать школьные навыки через:

- короткие ежедневные сессии;
- адаптивное повторение;
- игровые механики;
- марафон;
- XP и streak;
- творческие задания;
- мягкие подсказки;
- визуальный прогресс;
- современный подростковый интерфейс.

В первой версии приложение работает **без backend и без реального AI API**.

AI-наставник в MVP должен быть реализован как управляемая логика подсказок и заранее подготовленные сценарии.

После проверки MVP архитектура должна позволять подключить реальный AI API позже без переписывания всего приложения.

# 9. Daily Session

Одна ежедневная сессия содержит:

## Stage 1 — Warm-up

2–3 лёгких задания из уже знакомых навыков.

Цель:
быстрый успех.

## Stage 2 — Weak Spot

2–4 задания по одному слабому навыку.

## Stage 3 — Transfer

1 новое задание на тот же навык в другом контексте.

## Stage 4 — Creative Challenge

1 творческое задание.

## Stage 5 — Surprise

1 случайный игровой формат.

## Stage 6 — Complete

Экран результата.

# 13. Формат учебного объекта

Каждый вопрос должен иметь структуру примерно такого типа:

```js
{
  id: "math-mult-001",
  subject: "math",
  module: "multiplication",
  skillId: "math.mult.tables_7",
  type: "multiple_choice",
  difficulty: 1,

  prompt: "7 × 8 = ?",

  options: [48, 54, 56, 63],

  correctAnswer: 56,

  hints: [
    "Вспомни соседний пример.",
    "Можно взять 7 × 7 и добавить ещё одну семёрку.",
    "7 × 7 = 49. Добавь 7."
  ],

  explanation: "7 × 8 = 56",

  tags: ["hard_pair"],

  creativeVariant: null
}
```

Для разных типов задач структура может расширяться.

# 22. Boss Day

В MVP достаточно одного рабочего шаблона Boss Day.

Он должен:

- смешивать навыки недели;
- содержать 8–10 заданий;
- сравнивать текущий результат с предыдущими;
- показывать рост.

Пример:

Было:
7×8 — 7.4 sec

Сейчас:
7×8 — 3.1 sec

Не сравнивать с другими детьми.
